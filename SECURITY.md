# Security policy

## Supported versions
Only the latest release on `main` (and the live site built from it) receives fixes.

## Reporting a vulnerability
Please use GitHub's **private vulnerability reporting**: *Security → Report a vulnerability* on
https://github.com/fsantibanezleal/PitStudio/security. Do not open a public issue for security problems.

## What to expect
Acknowledgement within 7 days, an assessment within 30 days, and a fix or mitigation plan for confirmed issues.
Credit is given in the release notes unless you prefer otherwise.

## Scope
In scope: this repository's code, workflows and the static site it publishes. Out of scope: third-party services
(GitHub Pages hosting, dataset hosts), and the web app's access gate — it is a demo gate, not a security boundary,
and all published content is intentionally public.
