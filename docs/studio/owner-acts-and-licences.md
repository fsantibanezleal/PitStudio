# Maintainer acts and licences

> The one-time legal, account and administrator acts the studio depends on — written so that anyone reproducing
> PitStudio knows what to accept, what to install with admin rights, and what degrades if they do not. · Part of:
> [Studio](README.md) · Related: [Environments](environments.md) · [Sources and licences](../data-contract/sources-and-licences.md) ·
> [DEC-0004](../architecture/decisions/DEC-0004-proprietary-sdks-reference-only.md) · [Set up the studio](../guides/set-up-the-studio.md)

## What and why

Some steps cannot be automated or delegated: accepting a licence is a legal act of the person who runs the software,
creating an account is personal, and installing a driver needs administrator rights. PitStudio's maintainer performs
these on the reference machine; a reader reproducing the project performs the same acts on theirs. The design rule
is that **every act is optional or has a fallback**: refusing one turns a tool page into "not run" or removes one
optional arm, and nothing else blocks. Credentials never enter the repository and CI never needs them.

## Licence acceptances

| Act | Needed for | What it accepts | If not given |
|---|---|---|---|
| **NVIDIA software terms for Isaac Sim** (at first import, or `OMNI_KIT_ACCEPT_EULA=YES`) | `studio/isaac/` | the Isaac Sim EULA and NVIDIA's software terms [1] | the Isaac Sim lane (Replicator data, RTX clips, rain lidar, vehicle twin) does not run and its tool page shows "not run"; the open lanes are unaffected |
| **kit-app-template licence prompt** (the first `template new`) | generating USD Composer and USD Explorer locally | "the Omniverse Licensing Terms" [2] | Isaac Sim's own GUI is used for review; the Composer / Explorer page shows "not run" |
| **Hugging Face gated terms for Cosmos-Reason2-2B** + a read token | downloading the official weights | contact sharing and the NVIDIA Open Model License [3][4] | the Cosmos tasks run only on the Apache-2.0 Qwen3-VL-2B control model; the Cosmos page shows "not run" |

What these licences mean for the repository (PitStudio's reading, not legal advice):

- **Omniverse** has been free for development and production use since May 2026 [5]; NVIDIA software is still
  licensed only to run on NVIDIA platforms, and copying or distributing it is not granted [6][7]. PitStudio publishes
  only its own code, USD and outputs, never NVIDIA binaries, assets, engines or caches
  ([DEC-0004](../architecture/decisions/DEC-0004-proprietary-sdks-reference-only.md)).
- **Outputs.** Isaac Sim's licence FAQ allows selling outputs such as "simulation videos, analytic reports, or
  datasets" without an enterprise licence [8]; the NVIDIA SLA gives the customer its own products [7]. Renders of our
  own procedural and CC0 scenes are therefore published under CC-BY-4.0. No published scene contains NVIDIA asset-library
  content.
- **Performance data.** The NVIDIA SLA §8.9 forbids publishing benchmark or performance data of the software without
  written permission [7], and the TensorRT for RTX licence does the same (§2.13) [9]. Isaac Sim, Kit, Replicator, ovrtx
  and TensorRT for RTX numbers stay local. The regular TensorRT licence has no such clause [10], so TensorRT numbers of
  our own models are published ([DEC-0005](../architecture/decisions/DEC-0005-performance-data-licence-rule.md)).
- **Cosmos.** Anything that shows Cosmos outputs says "Built on NVIDIA Cosmos"; the weights are never redistributed;
  guardrails are never bypassed, because that terminates the licence [4].
- **Template code.** Files generated by kit-app-template carry NVIDIA proprietary headers and are "Derivative Samples";
  they stay outside the repository [2][11].

## Administrator acts

The studio's automation installs nothing that needs elevation; these are the maintainer's acts:

| Act | When | Purpose | If not given |
|---|---|---|---|
| Windows long paths (`LongPathsEnabled = 1`) | before installing Isaac Sim | Isaac Sim's pip install may need long-path support [1][13] | the Isaac Sim install may fail on deep paths |
| 3–5 **Nsight Systems** captures run as administrator, and a one-time **GPU performance-counter** setting | the data-and-models phase, optional | kernel-level GPU evidence; "You must run the CLI on Windows as administrator", and counters are restricted by default [14][15] | GPU evidence stops at NVML telemetry and `torch.profiler` timelines |
| An NVIDIA R595 driver ≥ 595.97 | **only if** Isaac Sim 6.1 fails the Compatibility Checker on the installed R580 driver | the driver Isaac Sim 6.1 was tested on [16] | Isaac Sim 6.0.0.1 is used ([DEC-0008](../architecture/decisions/DEC-0008-isaac-sim-version-by-compatibility-checker.md)) |
| CUDA toolkit + Visual Studio Build Tools | **only if** Brush fails on the GPU | the JIT build of gsplat for the splat survey | case E2 uses DEM differencing only |

Per-user installs that need no elevation — a uv-managed Python 3.12, the project environments, portable FFmpeg 8.1
LGPL, llama.cpp, COLMAP, Brush, MakeHuman and the Nsight redistributable archives — are done by the operator and
verified by version and SHA-256 ([Environments](environments.md)).

## Optional cloud spend

Cosmos Transfer 2.5 does not fit a 16 GB GPU. A one-day cloud rental (about USD 30–80 by arithmetic from public list
prices) could add one arm to the B2 study, **only** if the synthetic-to-real gap there turns out large. Default: no
([Cosmos Predict / Transfer, not adopted](../frameworks/not-adopted-cosmos-predict-transfer.md)).

## Assumptions and limits

- Licence texts change. PitStudio records which text it read: the TensorRT probe pins the licence file by SHA-256, and
  a changed text drops results to local-only until it is re-read ([Capabilities probe](capabilities-probe.md)).
- The free-production announcement does not list every product; Isaac Sim's additional licence still restricts Kit use
  outside Isaac Sim and Isaac Lab, which is why Composer runs on its own Kit tree [17].
- This page explains the project's choices. It is not legal advice.

## In PitStudio

- On the reference machine: long paths are enabled and the NVIDIA software terms are accepted; the Hugging Face terms,
  the kit-app-template prompt and the Nsight captures are pending. Every tool page states which act it waits for.
