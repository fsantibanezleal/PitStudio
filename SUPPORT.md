# Support

- Questions and ideas: GitHub Discussions (or an issue labelled `question`).
- Bugs: open an issue with the bug template (steps, expected vs actual, browser/OS, commit or version).
- Data problems: use the data-issue template.
- Documentation: start at [`docs/README.md`](docs/README.md).

This is a research project maintained in spare time; there is no guaranteed response time.
